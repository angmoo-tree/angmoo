## 구현과 책임

Social의 상세 v2는 URL로 선택한 게시글/답글을 subtree의 기준으로 삼는다. 직접 부모와 canonical root를 구분하며, 페이지·차단·공개 여부·ID를 서버에서 검증한다. 사용자 대댓글은 즉시 부모의 실제 상대에게 Inbox를 만들고 source ledger/event와 한 UoW로 저장한다. 자동 SNS의 root-only 정책은 유지한다.

사용자 좋아요는 World owner의 scoped PostLike 원본을 PUT/DELETE로 설정·취소한다. 변화마다 audit_only 근거를 남기며 직접 관계 점수나 AI 요청을 추가하지 않는다. 조회는 페이지 단위 count/viewer/capability를 묶어서 읽고, 글로벌에서 같은 World의 글도 서버가 제공한 context로만 연결한다.

World Home에만 공통 상단바를 남기고, 비홈 화면은 콘텐츠 헤더를 쓴다. 답글은 사용자 아바타·이름·빈 입력창과 숨김 label/Send, 반응은 왼쪽 답글→좋아요, Feed/Chat 사진·Send는 오른쪽 인접 그룹이다. World 프로필은 글로벌 anatomy와 원본 이미지를 계승한다. World Chat 개수 제한만 해제하고 권한·동일 tuple·생성 예산·모델/lease 보호를 유지한다. Chat에는 단일 메시지 scroll, compact 모델 footer, lazy Memory/진단 Dialog를 연결했다.

Characters가 전체 authored-name/macro 의미를 먼저 검증하고, Routine/공통 값 finalizer가 strip 후 thought280/topic300/novelty500 Unicode code point 접두부를 보존한다. 공개 title160/body4000은 strict하다. receipt는 execution/checkpoint에 남기며 내부 키를 LLM이나 공개 DTO로부터 신뢰하지 않는다. Chat thought port도 잘릴 tail을 먼저 검증한다.

신규 SNS run은 combined 정책과 모델 예산 revision을 고정한다. 같은 SDK 준비 구성을 공식 models/countTokens port에 전달하며 모델 입력/출력 한도를 별도로 적용한다. 필수 입력을 자르거나 새로운 제품 토큰 상한을 추가하지 않는다. 필요하면 가장 오래된 Today 기록, 온전한 Memory packet 묶음 순서로 제외하고 다시 계수한다. cache/receipt32, 영속 모델 조회·계수 시도256과 10 normal/5 recovery/15 total 생성 예약을 유지한다. 옛 run은 저장된 split/combined·legacy 입력 정책으로 재개한다.

## 실제 커밋·최종 보존 근거

승인 기록 `AR-WORLD-UI-SNS-OUTPUT-20261005`는 실제 signed 구현 커밋의 143개 source blob·117개 정의·12개 기존 단언 변경·32개 API/스키마 차이를 기록한다. ORM delta0이며 새 파일29개·새 node126개를 공식 --append로 추가했다. 과거 승인/추가 records와 frozen source/backend/frontend checkpoints, P8-L-D digest는 그대로다.

공식 frontend 보존 검사 **324 source PASS**, backend의 source/contracts/nodes 보존 검사 **PASS**이며 정확한 결과·HEAD는 JSON의 preservation_results에 있다. checker가 실제로 소유한 순수 AST memo만 주기적으로 비워 동일 자료를 다시 파싱했고 validator·허용 변경·단언·판정은 바꾸지 않았다. Chat 원본 보호·위조 거절 검사도 원 파일을 수정하지 않고 전체 scope를 재검사했다.

최초 backend 보존 gate는 새 단언 증거가 개별 Assert AST로 저장되어 공식 Module AST와 일치하지 않는 오류로 실패했다. 그 예외 후 보호 계보가 비워져 현재 node5,233개에 도입 증거 없음이 연쇄 보고된 것이며, 5,233개 기능 테스트가 실패했다는 뜻은 아니다. 실제 구현 커밋과 부모에서 12개 단언 증거를 공식 normalized_assertion으로 다시 추출했고, 원 검사기의 단언 비교 12개를 먼저 통과한 뒤 전체 gate를 다시 실행했다. 제품 코드·단언·검사 기준·과거 승인 기록은 수정하지 않았다. 최초 log와 정정 범위는 backend_preservation_first_failure에 연결했다.

52 SKIP는 명시적 성능 실행6·실제 Vec1 확장 미제공21·격리 PostgreSQL 미설정21·선택적 사용자 원본 미제공3·public profile에서 제외된 hosted lifespan1이다. 제외 이유와 최초 실패→현재 node 결과는 full_backend_review에 저장했다. 이전 진단용으로만 존재했던 Writer node1개는 현재 수집/최신 결과 수에 합산하지 않았다.

이 문서와 append 증거만 별도의 signed 로컬 커밋에 저장하고 마지막 branch/HEAD/clean 및 source 정합성을 읽기 전용으로 확인한다. 그 최종 커밋 SHA는 자체 참조로 추정하지 않고 workspace 계획 및 로컬 closeout 원자료·Git log로 확인한다.
